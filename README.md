# Automated Trucking Management Platform

A Flutter user-interface prototype for a trucking-management dashboard. This repository is part of a BS Software Engineering Final Year Project focused on improving coordination among truck owners, drivers, customers, and logistics managers in Pakistan.

## Current Repository Status

**Prototype — not a production-ready platform.**

The code currently implements a Flutter dashboard interface with:

- A navigation drawer
- Summary cards for loads, deliveries, trucks, and earnings
- A placeholder area for a future loads table
- A cross-platform project structure generated by Flutter

The dashboard values are sample data. Authentication, persistent storage, APIs, payments, notifications, maps, and real-time tracking are **not implemented in this repository yet**.

## Current Technology

- Flutter
- Dart
- Material Design widgets

## Planned Architecture and Features

The original FYP design proposes the following future work:

- Customer and driver authentication
- Shipment creation and job assignment
- Persistent load and vehicle data
- Admin and logistics-management workflows
- REST API integration
- Location and shipment-status tracking
- Payment and notification integrations
- Automated tests and deployment configuration

These items describe the project roadmap and should not be treated as implemented features.

## Run Locally

### Prerequisites

- Flutter SDK compatible with Dart SDK `^3.5.2`
- A configured Flutter development environment

### Steps

```bash
git clone https://github.com/khubaibrazi/automated-trucking-management-platform.git
cd automated-trucking-management-platform/Automated_Trucking_management_System
flutter pub get
flutter run
```
